#### **Description:**

This repository contains a component of a larger Airport System, specifically focusing on the passenger seating plan functionality. 
Developed as a first-year university group project, this module allows users to interact with a graphical representation of an aircraft's seating layout.

This project comprises a core component of a comprehensive airport system, specifically managing the aircraft seating plan. 
It demonstrates robust Java development skills, focusing on user interface design and data management within a collaborative environment.

-----

## Getting started:
To run this Java application, you will need a Java Development Kit (JDK) installed on your system (Java 8 or higher is recommended) and an Integrated Development Environment (IDE) such as Eclipse.
Once you have those installed, follow these steps:

**1. Clone the repository:**
```
> git clone <repository-url>
```

**2. Import into Eclipse (or your preferred IDE):**
```
> Open Eclipse.

> Go to File > Import....

> Select General > Existing Projects into Workspace and click Next.

> Browse to the cloned Seating-Plan directory and select it.

> Click Finish.
```


**3. Run the Application:**
```
> Locate the main class (e.g., Main.java or SeatingPlanApp.java) within the src folder in your IDE's Package Explorer.

> Right-click on the main class.

> Select Run As > Java Application.
```

## Features:
The Airport System - Seating Plan module provides the following key functionalities for users:
- **Flight and Plane Selection**: Users can select a specific flight and then choose the desired aircraft.
- **Seat Selection**: Users are presented with a visual map of the seating layout for the selected plane.
- **Ticket-Based Seat Limits**: The number of seats a user can select is strictly limited by the amount of tickets they have purchased.
- **Availability Check**: Only seats that are currently untaken can be chosen by the user, preventing double bookings.
- **Visual Seating Map**: A clear, interactive map allows users to visualise the aircraft's seating arrangement.
- **Ticket Integration** : Once selected, the chosen seat numbers are automatically added to the user's flight tickets.
